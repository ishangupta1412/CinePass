About CinePass

A browser-based booking system built with HTML, CSS and JavaScript.

CinePass is a web based movie ticket booking platform that lets users browse the movies running in nearby theatres, pick a convenient show and reserve their seats in advance. The idea came from the long queues at ticket counters during weekend releases.

The entire website runs in the browser using HTML, CSS and JavaScript. Movie details, show timings and seat availability are handled with JavaScript objects, and every confirmed booking is stored in the browser so the ticket can be reopened any time.

  • ✓
    Browse and filter movies by genre or search by name and language.
  • ✓
    Seat selection with live availability, categories and automatic price calculation.
  • ✓
    Instant ticket with a unique PNR that can be printed or saved.
  • ✓
    My Bookings page to review or cancel a reservation.
